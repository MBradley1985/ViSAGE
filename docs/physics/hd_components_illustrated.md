# HD Components, Illustrated

<div class="hdc">
<p class="hdc-intro">How ViSAGE builds every part of an HD galaxy from one SAGE26 catalogue row: the fields it reads, the recipe it applies, the literature behind it, the code, and the result drawn by the app's own GPU ray-marcher. Every tile is a real galaxy (Millennium, z = 0, run <code>millennium_DarknDusty</code>, unless noted), rendered off-screen with <code>visage.hd</code>. Sections 1-9 show each galaxy as a plain SAGE26 run sees it (the annulus and dust fields removed, which mode 1 leaves every shared output identical to); sections 10-11 add DarkSAGEMode and DustySAGEMode; section 12 a lightcone's photometry. 'Removed' tiles rebuild the same galaxy with one recipe term set to zero at the full model's exposure; amber tiles are |full - removed|, stretched. GI = SAGE26 GalaxyIndex. SAGE26 has no structure inside a galaxy: arm patterns, cluster positions and filaments are drawn procedurally (seeded by GalaxyIndex); every amount, size, rate, colour and switch is set by the catalogue as described. The same in text: <a href="../hd_components/">HD Galaxy Components</a>.</p>
<div class="hdc-pipe"><div class=""><b>Catalogue row</b><span>model_N.hdf5, annuli, a cone</span></div><div class=""><b>adapter</b><span>SageGalaxy, physical units</span></div><div class="hdc-key"><b>recipe_from_sage</b><span>GalaxyRecipe</span></div><div class=""><b>build_disk_maps</b><span>old, young, dust, lanes, HI, H2</span></div><div class=""><b>build_points</b><span>clusters, HII, stars, debris</span></div><div class=""><b>context</b><span>tidal, jellyfish, strip; photometry</span></div><div class=""><b>Exposure + gpu.prepare</b><span>textures, star grids, atlas</span></div><div class="hdc-key"><b>GLSL ray-march</b><span>every pixel, every frame</span></div><div class=""><b>tone map + Gas</b><span>asinh, screen-blended gas</span></div></div>
<p class="hdc-note"><i class="hdc-swatch"></i>Gold: the two stages everything hinges on. recipe_from_sage turns the SAGE26 numbers into every decision (each row below is a part of it); the GLSL ray-march makes the picture, per pixel on the GPU.</p>
<h2 class="hdc-sec" id="1-shape-size-and-brightness">1  Shape, size and brightness</h2>
<p class="hdc-intro">Every HD galaxy starts as one catalogue row. visage/hd/adapter.py converts it to physical units (masses to Msun, radii Mpc/h to kpc, SAGE26&#x27;s lookback merger times to time since the event at the galaxy&#x27;s own epoch) as a SageGalaxy; recipe_from_sage() turns that into a GalaxyRecipe; random choices are seeded by GalaxyIndex, so a galaxy always looks the same.</p>
